# _inbox — сюда скидывай файлы для сайта

Папка-приёмник. Ты кладёшь сюда материалы по проекту, пишешь мне
«забери из inbox <проект>» — я обрабатываю и заливаю на сайт.

Файлы отсюда **не попадают в git** (см. .gitignore) — это личное рабочее
пространство. После обработки я подчищаю папку.

---

## Как добавить / обновить проект

1. Создай папку с латинским именем-слагом проекта, например `_inbox/my-cafe/`
   (слаг = имя папки в `projects/` и в адресе, строчными через дефис).

2. Положи туда что есть — **всё опционально**, клади только то, что меняешь:

   ```
   _inbox/my-cafe/
     project.md      ← метаданные (заголовок, год, теги, описание, задача)
     page.html       ← экспорт страницы из Tilda (для новой или обновлённой страницы)
     media/          ← картинки и видео (я залью в Supabase, ссылки пропишу сам)
   ```

3. Скажи мне, что с этим делать. Примеры:
   - «залей новый проект my-cafe из inbox»
   - «обнови нитку: замени видео из inbox/nitka/media»
   - «поменяй описание союза — project.md в inbox/soyuz»

---

## Что я делаю сам (тебе не нужно об этом думать)

- Заливаю картинки/видео из `media/` в Supabase Storage, переписываю ссылки.
- Сжимаю видео, если оно больше 50 МБ (лимит Supabase).
- Применяю единое оформление: двуязычная шапка, удаление блока контактов,
  фон `#000000 → #0a0a0a`, блендинг видео, перевод английского текста на русский.
- Подключаю `projects/<слаг>.html` и добавляю проект в список (`main.js`).
- Проверяю в браузере (десктоп + мобилка) и пушу.

---

## Форматы файлов

- **Страница проекта** — HTML-экспорт из Tilda (Zero Block). Клади как `page.html`.
  Если экспорт с картинками/скриптами в подпапках — клади всю выгрузку в `media/`
  или отдельную папку, я разберусь.
- **Картинки** — png / jpg / svg. (svg остаётся в git, растр уходит в Supabase.)
- **Видео** — mp4 / mov / webm.
- **Метаданные** — `project.md` по шаблону из `_inbox/_template/project.md`.

---

## Обновить уже опубликованный проект

Клади в `_inbox/<слаг>/` только то, что меняется:
- новые картинки/видео → `media/`
- новый текст/описание → `project.md` (заполни только изменившиеся поля)
- новая версия страницы → `page.html`

и скажи, что именно обновить.
