# _inbox — сюда скидывай файлы для сайта

Папка-приёмник. Под каждый проект уже создана своя папка с именем-слагом
(как в `projects/` и в адресе). Внутри — `project.md` с текущими данными
и папка `media/`.

Ты кладёшь файлы в папку нужного проекта, пишешь мне «обнови <проект> из
inbox» — я обрабатываю и заливаю на сайт.

Файлы, которые ты кидаешь (картинки, видео, экспорты страниц), **в git не
попадают** — это личное рабочее пространство. В репозитории хранятся только
структура папок и `project.md`. После обработки я подчищаю дропы.

---

## Как обновить проект

Открой папку проекта, например `_inbox/nitka/`, и положи туда то, что меняешь:

```
_inbox/nitka/
  project.md      ← метаданные (заголовок, год, теги, описание, задача)
  media/          ← новые картинки и видео → залью в Supabase
  page.html       ← новый экспорт из Tilda (если меняешь саму страницу)
```

Всё **опционально** — клади только изменившееся. Потом скажи, например:
- «обнови нитку — новое видео в inbox/nitka/media»
- «поменяй описание союза — правил project.md в inbox/soyuz»
- «замени картинки в рассвете из inbox»

Текст (описание/задачу) можно менять прямо в `project.md` — поправь поля и
скажи обновить.

## Проекты без исходника

У пяти проектов в Tilda-выгрузке нет страницы (`tula-marathon`, `puppai`,
`212f`, `soroka`, `volunteer-71`) — в их `project.md` это помечено. Чтобы
их опубликовать, нужна страница: либо экспорт из Tilda (`page.html` +
`media/`), либо скажи, из чего собирать.

## Что я делаю сам

- Заливаю картинки/видео из `media/` в Supabase Storage, переписываю ссылки.
- Сжимаю видео, если больше 50 МБ (лимит Supabase).
- Держу единое оформление: двуязычная шапка, удаление блока контактов,
  фон `#000000 → #0a0a0a`, блендинг видео, перевод английского на русский.
- Обновляю `projects/<слаг>.html` и список в `main.js`.
- Проверяю в браузере (десктоп + мобилка) и пушу.

---

## Форматы

- **Картинки** — png / jpg / svg (svg остаётся в git, растр уходит в Supabase).
- **Видео** — mp4 / mov / webm.
- **Страница** — HTML-экспорт из Tilda, клади как `page.html` (+ ассеты в `media/`).
- **Метаданные** — `project.md` (уже лежит в каждой папке, просто правь поля).
